# Vicky 7.4

## Overview

Vicky 7.4 improves feed resilience and factual safety.

## Added

- Automatic health checks during normal RSS collection.
- Persistent feed report in `cache/feed_health.json`.
- Offline German-to-French and English-to-French translation.
- CTranslate2 INT8 translation with dedicated OPUS-MT models.
- One original headline per AWTRIX message.
- Automatic fallback to the unchanged original title if translation fails.

## Changed

- A broken or empty RSS feed no longer blocks healthy sources.
- Live bulletins no longer use generative rewriting.
- French headlines remain unchanged.
- German and English headlines are translated independently.
- The middle-button bulletin uses the same safe translation path.

## Translation models

Expected local model directories:

- `/home/gerd/translation-models/opus-mt-de-fr`
- `/home/gerd/translation-models/opus-mt-en-fr`

The base directory can be overridden with the environment variable
`VICKY_TRANSLATION_MODELS`.

## Safety

Vicky rejects empty, excessively long, or strongly repetitive translations.
When a translation cannot be trusted, the original headline is displayed.
