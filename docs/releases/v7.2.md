# V7.2 — News Engine

V7.2 moved Vicky closer to a real news engine instead of a simple RSS display.

## Added

- Persistent replay cache for the most recently selected bulletin
- Persistent output-language selection
- Shared ranking before publication
- Better bulletin scheduling
- More detailed logs for feed loading, pool additions and next bulletin time
- Clearer separation between polling, selection, publication and replay

## Current behaviour

Vicky polls enabled feeds, adds unseen stories to a shared pool, ranks candidates and sends a compact bulletin to AWTRIX. The last selected messages are stored so a button action can replay them without rebuilding everything from scratch.

## Known limitations discovered during operation

- The pool file can grow to hundreds of entries.
- Old stories may survive longer than intended.
- Cross-source duplicate detection is not yet strong enough.
- Only five feeds may be active even when more sources exist elsewhere in the project.
- Feed configuration and source priorities are not yet externalised.
