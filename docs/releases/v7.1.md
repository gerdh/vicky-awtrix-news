# V7.1 — Foundation

V7.1 stabilised the existing V6 installation and prepared Vicky for further development.

## Main capabilities

- Continuous operation as a systemd service
- RSS polling and a shared local news pool
- Local LLM editing, shortening and translation
- French, German and English output
- MQTT publication to AWTRIX custom apps
- Forced bulletin refresh from the AWTRIX middle button
- Automatic clearing after the configured visibility period

## Button workflow

The middle-button service creates a refresh request and restarts the news service. At startup, Vicky consumes that request, clears the existing news topics and generates a fresh bulletin from the available pool.

## Runtime environment

The reference installation runs on a Jetson Orin with Ubuntu, Mosquitto, llama.cpp and an AWTRIX Light.

## Known limitations

- Feed definitions are still part of the Python code.
- Pool size and story lifetime are not enforced consistently.
- Similar reports from different sources may still appear as separate stories.
- Portability to new systems has not yet been fully tested.
